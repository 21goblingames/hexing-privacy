# Hexing privacy policy

The privacy policy for **[Hexing](https://21goblingames.github.io/)**, a roguelite tower defense deckbuilder by 21 Goblins, published at:

**https://21goblingames.github.io/hexing-privacy/**

## The short version

- The Hexing demo can send **anonymous gameplay events** (mission and wave reached, how a run ended, run length, game version, optional typed feedback) so the game can be balanced and the spots where players get stuck can be found.
- Each event carries a **random install ID** made on first launch. It isn't linked to your Steam account, name or email.
- Data goes to a Google Form and Sheet owned by the developer, is **never sold or used for ads**, and is deleted after 12 months.
- **Opt out** any time in the game: Settings → Data → "Share gameplay data".
- To see or delete your data, email [21goblingames@gmail.com](mailto:21goblingames@gmail.com) with your install ID (`InstallId` in `telemetry.cfg`, in the game's user data folder).

The full policy in [`index.html`](index.html) is the one that counts; this summary is just for skimming.

## About this repo

A single static page served by GitHub Pages. It borrows its background and icon from the [main site](https://github.com/21goblingames/21goblingames.github.io). Push to `main` to update it, and change the "Last updated" date when the policy's content changes.
